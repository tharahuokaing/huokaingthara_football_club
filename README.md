# huokaingthara_football_club
⚽ Huokaing Thara Football Club (HTFC) Website

Welcome to the official web repository for Huokaing Thara Football Club (ក្លឹបបាល់ទាត់ ហួកាំង ថារ៉ា). This project is a modern, responsive, and bilingual website built to showcase club news, player rosters, team history, and upcoming match information.

🌟 Key Features

Bilingual Support (English & Khmer): Seamlessly toggle between English and Khmer (ភាសាខ្មែរ) with a single click.

Responsive Design: Mobile-first, layout optimized for smartphones, tablets, and desktop displays.

Pure Web Technologies: Built with vanilla HTML5, CSS3, and JavaScript—lightweight and fast loading with zero external frameworks required.

Modern UI/UX: Styled using custom CSS with flexbox, grid dynamics, and integrated icons via FontAwesome.

📁 Repository Structure

huokaing-thara-fc/
│
├── index.html     # Main HTML structure containing English & Khmer content
├── style.css      # Custom styling, layout design, and responsive media queries
├── script.js     # JavaScript logic for language switching and UI interactions
└── README.md      # Project documentation


🚀 Quick Start & Installation

No complex dependencies or build tools are required to run this project.

Clone the Repository:

git clone https://github.com/your-username/huokaing-thara-fc.git


Navigate into the project directory:

cd huokaing-thara-fc


Launch the site:
Simply open index.html in your web browser, or use a live server extension (such as VS Code Live Server).

🌐 Language Toggle Setup

The language switching mechanism utilizes CSS visibility classes (.en-text and .kh-text). The JavaScript engine dynamically handles element display rules upon user interaction:

    // Toggles display state between .en-text and .kh-text

🎨 Customization & Branding

To personalize this website for your club:

Logo & Colors: Change the primary colors (#0b1f36 and #ffcc00) inside style.css to match your club's official kit colors.

Roster Updates: Modify the squad section in index.html to add real player profiles, images, and position descriptions.
